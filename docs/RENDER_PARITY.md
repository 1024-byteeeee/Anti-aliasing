# 跨版本渲染基准

基准为 1.21.8。SSAA 缩小、GUI 实体透明采样、TAA 累积、锐化均使用公共着色器；版本适配只处理渲染入口、矩阵获取、缓冲区与纹理 API。

## 区块线与原生调试线

七版本均使用 `assets/taa/shaders/include/line_position.glsl`：先裁剪中心线，再按实际渲染尺寸展开，端点和颜色使用同一裁剪区间。线宽只计算一次：基础像素宽度 × SSAA 宽高倍率 × 用户线宽倍率。红黄青线基础宽度为 1，蓝线为 2。

颜色阶段只检测世界深度，按细线到蓝色主线的顺序覆盖；全部颜色完成后，以相同几何、相同深度比较补写深度，不修改颜色。两阶段在透明场景和云之前完成，兼顾重合处颜色与后续遮挡。先将正确的线条颜色保存到透明图层，再在深度阶段结束后复制深度快照。世界绘制完成后、SSAA 缩小之前，将颜色图层按当前深度与快照的比较结果合成回画面，防止光影最终合成覆盖线条。红蓝重合处的颜色顺序只确定一次，补回时不再重绘相互竞争深度的线几何。已移除旧的视口偏移扩展路径。

| 版本 | 适配入口 | 版本差异处理 |
| --- | --- | --- |
| 1.16.5 | `BufferUploader._end`，固定功能矩阵 | 原生线转换成三角形；区块网格按基准生成，高度为 0～256 |
| 1.17.1 | `BufferUploader._end`，旧 `Matrix4f` | 区块网格补齐青黄交替配色；读取维度高度 |
| 1.18.2 | `BufferUploader._end`，旧 `Matrix4f` | 区块网格按基准生成；读取维度高度 |
| 1.19.4 | `ChunkBorderRenderer.render` / `BufferUploader._drawWithShader`，JOML | 区块线使用公共生成器和独立线宽；其他原生调试线在释放 `RenderedBuffer` 前复制顶点，保留绘制矩阵 |
| 1.20.6 | `ChunkBorderRenderer.render` / `BufferUploader._drawWithShader`，JOML | 与 1.19.4 共用后端，区块线保留传入 PoseStack 与全局模型视图矩阵各自的变换 |
| 1.21.8 | `ChunkBorderRenderer.render` → 独立 GPU 通道；其他调试线接入 `CompositeRenderType.draw` | 区块线不经外部批处理；其他原生条带入队时复制顶点，两阶段使用各自的绘制输入 |
| 1.21.11 | `ChunkBorderRenderer.emitGizmos` → 主 Gizmo 绘制阶段 | 独立生成基准网格，避免原版 4 像素主线、透明分组顺序和额外置顶区段框造成差异 |

1.16.5～1.18.2 的调试入口外层还会切换模型视图矩阵，不能提前刷新实体、碰撞箱和选中框的缓冲。1.19.4 / 1.20.6 只提前提交区块线对应的两个批次，其他缓冲仍在原版位置绘制。旧后端在提交时记录矩阵，并在结束时还原实际 OpenGL 状态。

1.21.8 的其他原生调试条带入队时立即复制顶点到模组持有的缓冲并释放原始 `MeshData`，不跨越调用边界保留外部共享缓冲。颜色和深度阶段分别创建可关闭的绘制输入，内部快照不经过 `RenderType.draw` 调用链，避免调用者复用缓冲或其他包装关闭输入后出现 `Buffer is no longer valid`。快照、绘制输入和展开几何使用不同的可复用缓冲，批次结束及异常时释放结果，资源重载时关闭缓冲。

线宽优先使用本模组的解析值，不再依赖可被其他模组重写的全局线宽。七版本区块线统一由公共生成器提供 1 / 2 像素基础宽度，再乘 SSAA 与用户倍率。1.21.8 的其他调试条带从绘制类型的线状态读取声明宽度，自动宽度按原始窗口尺寸计算；入队时保存计算结果。宽度写入每个顶点的 `PixelWidth`，着色器不读取全局 `LineWidth`，兼容格式的替换管线也可接入。此优先逻辑只在 SSAA 绘制期间生效。

Iris 1.9.6 的 `FullyBufferedMultiBufferSource` / `BufferSegmentRenderer` 会直接提交顶点而绕过 `CompositeRenderType.draw`。因此 1.21.8 的区块线由 `@WrapMethod` 在原渲染入口记录请求，在当前调试阶段结束时通过独立 GPU 通道完成颜色和深度绘制，不进入 Iris / ImmediatelyFast 的顶点批处理，也不依赖提高 Mixin 优先级。1.21.8 的 PoseStack 与全局模型视图矩阵分别保留，1.21.11 仍在主 Gizmo 阶段提交。实现不检测 Iris 是否安装，不修改 Iris 配置或全局渲染开关。

光影开启后，Iris 的 `finalizeLevelRendering` 会执行 composite / final，将最终颜色重写到主目标。七个版本均在 `GameRenderer` 的 `LevelRenderer.renderLevel` 调用返回后合成缓存图层，此时不再使用调试阶段的临时颜色目标。1.21.8 / 1.21.11 使用 GPU 纹理复制与独立颜色通道；旧版本使用独立 FBO 和深度拷贝，结束后还原 OpenGL 状态。合成器用 `texelFetch` 比较最终世界深度和线条深度快照，丢弃后来被更近场景遮挡的像素，其余像素保留已经确定的颜色，不写入深度。颜色通道不附加所采样的深度纹理，以避免读写反馈。缓存按 SSAA 尺寸复用，重建/关闭 SSAA 缓冲、资源重载和退出时释放。

## 界面与画面解析

- 世界、手部使用同一 SSAA 缓冲和公共 Lanczos 缩小着色器；HUD 保持原分辨率。
- GUI 实体使用独立透明缓冲，公共缩小着色器执行完整子像素平均，按预乘 alpha 合成。
- 1.21.8 / 1.21.11 接入原版实体预览纹理；较早版本接入 `InventoryScreen`，按原 GUI 坐标裁剪缓冲。
- TAA 与锐化参数及算法共用，具体矩阵类型、纹理采样器与后处理入口按版本适配。

## 校验范围

只进行七版本构建、预处理结果检查、发布包配置/资源核对、Mixin 目标与描述符检查、GLSL 语法检查，不启动游戏或单元测试。上述静态检查不能证明最终画面逐像素一致；游戏内按 [手动检查清单](SSAA_MANUAL_CHECKS.md) 在相同设置下逐版与 1.21.8 对照。
