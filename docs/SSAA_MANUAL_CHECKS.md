# SSAA 线宽与界面实体手动检查

当前实现覆盖 1.16.5、1.17.1、1.18.2、1.19.4、1.20.6、1.21.8、1.21.11。未运行客户端或单元测试，下列项目留给用户在游戏内确认。

1. 关闭抗锯齿，打开 F3+G、F3+B，记录区块边界、碰撞箱、视线和方块选中框的正常粗细。
2. 分别开启 SSAA 4×、9×、16×，比较线宽与可见度；旋转视角观察水平、垂直、斜线和交点。
3. 反复切换 SSAA、TAA、关闭抗锯齿，确认没有线宽累积，HUD、文字、菜单没有变粗。
   在线宽倍率中输入 0.5、1.0、2.0，点击“应用线宽倍率”或“完成”，检查线条粗细变化以及重新打开界面后的保存值。空值、多个小数点和超出 0.1～4.0 的值应提示错误；恢复默认设置后应为 1.0。
   在七个版本的 F3+G 中分别比较红、黄、青色细线和蓝色粗线，确保它们都随倍率变化；蓝线应保留约两倍的基础宽度。区块线按 1.21.8 的不透明颜色覆盖方式绘制，红色端点仍保留原版的 alpha 数据。
   固定线宽倍率，缓慢旋转视角并改变俯仰角，观察水平、垂直、斜线和经过相机附近的长线；线段不应在中部收窄、扭曲或随视角忽粗忽细。七版本的区块线四个角共用同一对完整端点及屏幕垂线方向，不再逐端点投影单位法线。
   特别在世界高度中间向下俯视再向上仰视：竖直区块线会跨过相机前后，必须先裁剪到可见中心线再展开。检查这些长线不应因穿过近裁剪面而变成宽楔形；靠近屏幕边缘的线段也应保持宽度。
   在七个版本中观察区块角落的蓝色竖线，特别是夜间和红蓝重合的位置：改变视角、SSAA 倍率和线宽倍率后，蓝线不应因红线穿插而变紫或闪色。调试线先按原版顺序绘制全部颜色，再统一补写深度，避免互相争夺深度；地形仍应正常遮挡线条，线宽及近裁剪行为保持正常。
   分别在快速、高品质、极佳画质下打开云，观察云层前后的红、黄、青、蓝线，尤其夜间：云不应覆盖位于云前的线条使其变暗；线段位于云后时仍遵守原版遮挡关系。再检查水、玻璃、粒子与雨雪，确保后续透明渲染没有因线条缺失深度而错误覆盖。
   特别比较方块选中框与区块线：自动线宽应按原始窗口宽度计算，在 1920、2560、3840 等窗口宽度下都不应重复补偿；七个版本均检查此项。
4. 在 SSAA 模式开启“界面实体抗锯齿”，打开生存和创造背包，移动鼠标观察角色边缘；关闭该选项对比原版预览。
5. 检查皮肤透明层、盔甲、披风、手持物品和附魔光效，角色周围应没有黑边、矩形背景或异常光晕，四肢和装备不应新增裁剪。
6. 修改 GUI 缩放、窗口尺寸、全屏状态、SSAA 倍率，开关配方书；确认角色大小、位置、鼠标跟随和裁剪正确。
7. 检查背包文字、物品图标、悬浮提示和界面背景，确认它们的清晰度及遮挡顺序保持正常。
8. 反复打开、关闭背包并按 F3+T 重载资源，确认没有残留画面、后续物品渲染异常或持续增加的显存占用。

七版本的区块线采用同一份 `line_position.glsl`，旧版本原生线改用三角形，不再使用视口偏移或 OpenGL 宽线。调节倍率时还应确认日志不再出现由宽线调用触发的 `GL_INVALID_VALUE` / `Operation is not valid from a preview context`。

跨版本对照时使用相同窗口尺寸、GUI 缩放、SSAA 倍率、线宽倍率与锐化选项，以 1.21.8 为参照。1.16.5 的区块线仍在 0～256，其他版本使用实际维度高度；只比较相同高度范围内的线条。1.16.5 / 1.17.1 应出现与基准一致的青黄交替网格；1.21.11 不应出现额外的置顶区段框，红线不应比基准更粗。
